AI 辅助批改

不配这个也能用 —— 所有打分、批注、统计、导出功能都不依赖 AI。 配上之后，AI 可以对着卷子给出建议分和评语草稿； 分数只有你点了「采纳」才会记进成绩，系统不会自己落分。

API Key 放这里就行 ——
用记事本打开这个文件，把智谱的 API Key 粘进去（不要带 # 号那几行），保存， 刷新本页面即可。填了 Key 就自动启用 AI，不用再点开关。 这个文件在 data 文件夹里，更新程序不会覆盖它。
智谱 GLM-4V、通义千问 qwen-vl 这类多模态模型要勾上； DeepSeek 的 deepseek-chat 是纯文字模型，不要勾 —— 不勾的话，每道题需要你把学生写的内容打进输入框，AI 才能批。

怎么拿到 API Key

  1. 打开 智谱开放平台，注册并实名。
  2. 在控制台里创建一个 API Key，复制出来。
  3. 用记事本打开本页最上面写的那个 API_KEY.txt， 把 Key 粘到最下面空的那一行，保存。带 # 号的几行是说明，不用动。
  4. 刷新本页，看到绿色的「已读到密钥」，再点一下「测试连接」。
  5. 显示「连接正常」就成了，回到批改台就能用 AI 了。

按量计费，批一道题几厘钱到几分钱。如果这台电脑上不了外网（单位内网管控）， 测试连接会失败，那就把 AI 关掉，其它功能照常用。
